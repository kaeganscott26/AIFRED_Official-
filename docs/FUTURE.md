# Future architecture

## Next gate: intelligence layer

The next project begins after the current machine is accepted:

```text
DAW -> EngineSnapshot -> ObservationSnapshot -> FilteredMixContext
```

That project may build a new intelligence layer behind `FilteredMixContext`. It must consume the deterministic contract and cannot redefine measurements, merge incompatible profile epochs, invent reference detail, or enter the audio callback.

Unimplemented candidates include personality and memory documents, FORGE-style audio tools, topology/inventory tools, long-term memory, delivery-compliance policies, and additional profiles. Current UI and host contracts must not expose them before implementation and validation.

## Final gate: Babylon GUI

Babylon remains the final project phase. The present `MetricDetail` and spectrum contracts prepare clickable meter views for peak, loudness, spectrum, correlation, crest, and stereo inspection. This pass does not build those views or redesign the frontend.
