# Website

## Purpose

`website/` will contain the future public presentation layer for the flagship rebuild.

The website presents the product. It must not duplicate backend source of truth or create conflicting deployment configuration.

## What Belongs Here

- Future website documentation
- Future website source after approval
- Future product/download/docs presentation planning
- Future support and privacy presentation work

## What Does Not Belong Here

- Backend route implementation yet
- Cloudflare deployment config yet
- Plugin code
- Admin-only controls
- Secrets or private operational data
- Copied old website code without approved migration

## Implementation Status

Implementation is not allowed yet.

This folder is Phase 1 skeleton only. Website implementation must wait until backend ownership and route contracts are aligned.
